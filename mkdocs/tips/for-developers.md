- [VSCode](https://code.visualstudio.com/) for source code editing.
- [Git](http://git-scm.org/) and [GitHub](http://github.com/) for source management.
- [Mkdocs](http://www.mkdocs.org/) for software documentation.
- [Latex](https://www.latex-project.org/) and [Overleaf](https://www.overleaf.com/project) to write papers.
- [pytorch](https://pytorch.org/) for Deep Learning projects.
